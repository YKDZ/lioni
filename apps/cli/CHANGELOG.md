# 更新日志

## 0.2.0

### 验证与 SDK 迁移

- 内部验证统一使用 Zod，简化检查器、术语、文本分析、CLI 与评测工具中的重复结构守卫，移除 Valibot 和旧 JSON Schema 转换依赖。核心与公开验证注入继续使用 Standard Schema，宿主无需选择 Zod；CLI 保持运行时验证与 Standard JSON Schema 描述。
- 检查工厂仅返回共同检查器契约，不再暴露内部 `configuration`、`configurationSchema` 和 `inputSchema` 成员。配置仍在创建检查时传入；需要复用的公开 schema 通过 Standard Schema 消费，不提供验证库专有方法。移除自定义 `TermSchema` 类型；手工构造 `MessageFamilyReference` 时须提供稳定的 `translationIdentity`。
- 输入验证异常继续提供项目异常类型、字段位置和原因，错误码、文案及排列顺序有所调整；业务诊断码与完整性状态保持其含义。领域数据保持有效字段和快照隔离，配置可以按声明转换或填默认值。

- 正式性能基准的业务输出保持一致。编译热点 schema 后，大规模术语发现耗时接近 0.1.2；本机一万比较组的缓存复用检查由约 105ms 增至 177ms，进程峰值内存由约 503MiB 增至 573MiB，迁移并非所有场景均有性能收益。

### 例外与缓存修复

- 修复内置 Vue I18n 语法、变量、受保护字面值、数量和消息族检查过度依赖全项目事实的问题，依据实际投影、策略及报告位置确定检查范围。数字对应和消息族通用工厂支持 `fingerprintInput` 显式声明宿主依赖；未声明时仍保留完整事实的保守默认值，沿用 0.1.2 的术语行为。
- 链接目标存在检查只关注直接引用键的存在状态；循环检查关注当前候选可达的完整消息图，包含缺失键、候选覆盖自身和目标正文缺失时回退原文的变化。
- 消息族每次重新发现全部同族已保存参照，不受报告展示上限限制。已知其他消息族的不完整信息不再影响当前族，不能排除相关的证据缺口仍保守处理；同次其他待写回候选不充当已保存参照。
- 消息族报告使用稳定源译身份替代参照的全局数组索引，并稳定证据顺序；无关记录增删或重排不会使证据定位、缓存或例外失效。修复按候选变化的宿主回调错误共享参照准备结果的问题。
- 缓存继续保存应用例外前的原始结果，每次应用当前例外；依据恢复时例外重新适用，未运行的检查显示本次未验证。更新受影响检查的实现版本，升级前为这些检查建立的例外需重新确认；术语检查的实现版本不因本次验证迁移而调整。

## 0.1.2

- 修复内置 Vue I18n 术语检查的例外和结果缓存受无关消息修改影响的问题；依据包含当前检查的文本、语言、对象、诊断位置及实际术语库。
- 原生术语工厂支持通过 `fingerprintInput` 显式声明业务依据，自动纳入本次加载的术语库数据；未配置时保留完整事实的默认依据。异步术语资料在生成指纹前加载，并由本次检查复用。
- 更新术语检查实现版本；升级前建立的术语例外需重新确认，其他检查项的例外不受本次实现版本调整影响。
- 移除仓库、CLI、检查包及术语评测目录中的 README 和独立发布说明，调整包文件清单与格式检查范围；补充检查指纹及可选结果缓存的接口注释。

## 0.1.1

### 破坏性变更

- 移除内置完成统计及其配置、SDK 判据与评估接口、报告和专用类型/错误，也移除 CLI `completion` 命令。宿主可根据 SDK 提供的原始记录、源译关联、读取完整性、正文可用性和 QA 结果自行定义完成状态与 CI 条件。
- 将填充配置 `sourceToContent` 迁移为 `createPlaceholderContent`，不保留旧别名。将 `translations.identityOf` 迁移为 `translations.keyOf`，返回值结构保持不变。

### 功能变更

- 原文被判定为变化时，更新默认用当前原文生成待译占位并覆盖已有译文或旧占位；默认填充复制原文正文，仍可配置自定义填充函数。没有比较基线时保留已有译文，仅补充已确认缺失的目标。
- 写回支持可选批量适配，沿用正式预检，并在批次结束后逐项回读确认；继续支持单项写回。
- 更新可选择组合记录比较基线。`--record-baseline` 默认关闭；只有覆盖全部配置语言、所有预期更新均已处理且回读确认成功后才推进基线，部分语言组合会在写入前拒绝。
- 发布工作流支持从默认分支人工启动，并使用 GitHub Actions OIDC 自动验收和发布同一份制品，不依赖长期 npm 发布令牌。

## 0.1.0

Lioni 首个公开版本，提供一个同时包含命令行和 TypeScript SDK 的 npm 包。

- 使用 `inspect`、`completion`、`baseline`、`update` 和 `qa` 管理多语言资源。
- 通过公开 SDK 读取宿主事实、选择质量检查候选，并运行检查器。
- QA 默认生成简洁的中文报告，也可显式获取完整结构化结果。
